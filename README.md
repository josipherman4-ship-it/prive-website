# Privé Academy website (V5 preview)

Static preview of the V5 creative-testing build of the "Plasma Technology Academy" redesign. Open `index.html`.

This repo is a deploy copy. The source, build tooling and GHL bundles live in Speedster at
`prive-os/projects/website-build/v5-creative-testing/` (`node tools/build.mjs` -> `dist/preview/`).
Edit there, rebuild, then re-sync here. Don't edit these HTML files directly.

- `treatments.html` is the Privé Studio Zagreb treatments page (Croatian, English nav and footer).
- `checkout.html` is a stub: the real checkout is a native GoHighLevel page.
- Forms on contact, fibroblast and treatments are static mocks until their GHL forms exist.
- `[needs: …]` markers are values still waiting on a decision (Google rating, guarantee).
