# Privé Academy website (V4 preview)

Static preview of the V4 "Plasma Technology Academy" redesign. Open `index.html`.

This repo is a deploy copy. The source, build tooling and GHL bundles live in Speedster at
`prive-os/projects/website-build/v4-plasma-technology-academy/` (`node tools/build.mjs` -> `dist/preview/`).
Edit there, rebuild, then re-sync here. Don't edit these HTML files directly.

- `treatments.html` is the V3 studio treatments page, carried over as-is.
- `checkout.html` is a stub: the real checkout is a native GoHighLevel page.
- `[needs: …]` markers are values still waiting on a decision (EU phone, Google rating, guarantee).
